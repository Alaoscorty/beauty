Créer moi une base de données sécurisée MongoDB Atlas dans un dossier api pour un projet React Native Expo. 
La base de données doit se connecter automatiquement dans le fichier apk et elle permettra à l'utilisateur d'entrer son numéro de téléphone peut importe le pays, 
de recevoir un code OTP par mail en utilisant nodemailer, 
avoir la possibilité de valider le code par mail en cliquant sur un bouton "valider mon code". 
Ensuite l'utilisateur sera créé avec un identifiant personnalisé comme : user_elagante_Xxx si c'est un client et Professionnels_elegante_xxx si c'est un professionnel. Un token sera généré. Lorsque l'utilisateur entre prochainement son numéro, s'il est dans la base de données il sera connecté immédiatement si non on lui envoie le code vérification pour créer son compte.

*Base de données Utilisateurs*

- La base de données Utilisateurs doit stocker les informations suivantes :
- Numéro de téléphone
- Code OTP
- Identifiant personnalisé (user_elagante_Xxx ou Professionnels_elegante_xxx)
- Token
- Type d'utilisateur (client ou professionnel)
- Les requêtes suivantes doivent être possibles :
- Sauvegarder : créer un nouvel utilisateur
- Modifier : modifier les informations d'un utilisateur
- Supprimer : supprimer un utilisateur
- Rechercher : rechercher un utilisateur par numéro de téléphone ou identifiant
- Connecter : connecter un utilisateur avec son numéro de téléphone et son code OTP
